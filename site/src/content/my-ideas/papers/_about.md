title: "About paper notes"
---

Files in this folder are per-paper `My Idea` notes owned by the repository owner.

- One file per paper, named after the paper's slug on the site
  (`site/src/content/my-ideas/papers/<paper-slug>.md`).
- Create one from any paper page with the "Create this note on GitHub" link, or by
  adding the file by hand.
- Automation may create a missing blank note. It must never rewrite, summarise,
  translate, reorganise or delete an existing one.

This `_about.md` file is a placeholder so the content collection is never empty;
files whose name starts with an underscore are not shown as notes.
